## u3dtest：Unity/团结引擎 AGV 调度 Demo（首个可用样本）

**背景**：用户在 `D:\yudao\u3dtest` 学 Unity（团结引擎 Tuanjie 1.10.4 = Unity 2022.3.62t16 分支，3D Built-in 模板）。
用户已知 Angular/React/Vue + ABP(C#) + Spring，要求全程用这些概念对标讲解 —— 这条对后续所有 unity 相关讲解有效。

**已建目录骨架**（`Assets/Scripts/`）：
- `Runtime/Core` 领域层（EventBus、GridMath、IPathFinder+BFS）
- `Runtime/Application` 应用层（WarehouseAppService）
- `Runtime/Infrastructure` 数据源（IWarehouseLayoutSource + HardcodedLayoutSource）
- `Runtime/Presentation` 表现层（AgvDemoBootstrap、ShelfPickable）
- `Runtime/Bootstrap` 组合根（DemoHost，预留 DI）
- `Editor` 编辑器专属（AgvDemoMenu：打开场景/运行/生成场景骨架）

**场景**：`Assets/Scenes/AgvDemo.scene`（手写 YAML，含 Main Camera / Directional Light / AgvDemo 挂两个脚本）。
脚本引用用**固定 GUID**写入 `.meta`，避免首次导入 Missing Script：
- AgvDemoBootstrap.cs → `4d5e6f708192a3b4c5d6e7f8091a2b3c`
- AgvDemoMenu.cs → `9a8b7c6d5e4f30211223344556677aab`
- AgvDemo.scene → `3c1d5e7a9b0f4c2d8e6a1b3f5d7c9e0a`

**功能**：6×5 网格、6 个货架(A-01~A-03 / B-01~B-03)，点击货架 → BFS 算最短路 → AGV 转向行走到位，支持自动跑 N 单。

**坑点记录**：
- Unity `.scene` 手写时 GameObject 的 `m_Component` 列表不能有空行/重复 `&id`，否则 Inspector 报错。
- 静态相机不需要 AudioListener，去掉可避免组件缺失警告。
- 用户环境无 Unity 命令行，无法批处理导包；采用「手写场景 + 固定 GUID」方案保证首次打开即可运行。
- 用户 `Packages/manifest.json` 为空模板默认值，未装 URP/HDRP/Addressables；建议后续补 `.asmdef`。
