# BizBuddy

#### 介绍
BizBuddy 是一个企业级智能业务运行平台，构建在 RuoYi-Vue-Plus 中后台底座之上，以 AgentScope Java 2.x 为智能体内核。
平台入口由智能体「小Z」统一接待，判断意图后路由给对应领域专家，专家回复直接交付用户；写操作经人工确认（HITL）后执行；
会话、路由、工具调用与用量全链路审计可追溯，并配套模型配置、知识库、MCP、技能、记忆、用量配额等运营管理能力。
