## MCP Tool 配置教学（module-ai → module-agent）

- 完成了"在 module-ai 配置 Tool 并通过 HTTP 版 MCP 供 module-agent 使用"的完整教学，最终定稿写入 `CODE-WIKI/07-mcp-tool-config-guide.md`。
- 关键结论（已核对真实代码）：
  - AI 服务端口是 **48090**（不是 48080）；HTTP 版 MCP 端点用 `streamable-http-endpoint: /mcp`。
  - 网关路由 `ai-mcp-server` 只匹配 `/sse, /mcp/message`，走网关需补 `/mcp`。
  - module-agent 的 `pyproject.toml` 没有 MCP 依赖，需加 `langchain-mcp-adapters` + `mcp`。
  - 权限方案：MCP 端点 `permitAll → authenticated`；工具 `apply()` 内 `hasPermission` 二次鉴权；角色→工具在芋道 `ai_chat_role.tool_ids` 配置，Agent 端不持有角色。
  - 规范写法：MCP 工具是异步加载，必须在 FastAPI `lifespan` 启动阶段先 `await load()` 再 `build_agent_registry()`，用 `AppContainer` 统一存放对象，替代模块级单例。
